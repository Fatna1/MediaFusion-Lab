# MediaFusion-Lab
MediaFusion Lab is a comprehensive multimedia processing desktop application that implements 8 core algorithms across four media domains: Image, Video, Audio, and Text. Built with Python and Tkinter, it features a modern dark-themed GUI and includes real AI-generation capabilities as a bonus feature.

📷 Image Processing (2 algorithms)
Grayscale Conversion – Convert RGB images to black & white using luminosity method

Edge Detection (Canny) – Detect object boundaries using multi-stage edge detection

🎥 Video Processing (2 algorithms)
Frame Extraction – Extract frames from video at configurable intervals

Motion Detection – Detect movement using frame differencing with visual bounding boxes

🎵 Audio Processing (2 algorithms)
FFT Analysis – Visualize frequency spectrum using Fast Fourier Transform

Noise Reduction – Remove high-frequency noise via low-pass filter (FFT + IFFT)

📝 Text Processing (2 algorithms)
Word Frequency Counter – Analyze text with relative frequency statistics

Caesar Cipher – Encrypt/decrypt text with classic shift cipher

🤖 AI Bonus (Independent Component)
Text-to-Image – Generate real AI images using Stable Diffusion (Pollinations.ai)

Text-to-Video – Create short videos from multiple AI-generated frames
